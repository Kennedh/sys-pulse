SysPulse 3.3 facilita conectar o serviço ou servidor de IA que já usa.

- Busque o serviço, conecte e carregue os modelos automaticamente.
- Autorize OpenRouter pelo navegador, sem copiar chave; use a conta Ollama ou chaves dos conectores diretos.
- Conecte GPT/OpenAI, Gemini, Claude/Anthropic, DeepSeek, Groq, Mistral AI, Grok/xAI, Together AI e Hugging Face.
- Use LM Studio ou outro servidor com Chat Completions, Responses, Messages ou API Ollama.
- Informe apenas o endereço base; escolha autenticação e modelo manual quando o catálogo não estiver disponível.
- Confira o provedor/modelo em uso e a origem efetiva de cada resposta. Conectar não inicia inferência.

Acesso, saldo, cotas e compatibilidade pertencem ao serviço e ao modelo. A opção anônima sem conta continua separada. Credenciais ficam em memória ou, opcionalmente no Windows, no cofre do sistema.

Instaladores e pacotes portáteis estão em Assets, com SHA256SUMS.txt. Modelos não acompanham o pacote. Consulte README e docs/validacao-3.3.md.
